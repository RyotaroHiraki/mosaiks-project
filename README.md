# Returns to Education in the U.S. with a college proximity instrument: a deep learning approach with satellite imagery

This repository contains the data analysis code and materials for my research project titled
"[Returns to Education in the U.S. with a college proximity instrument: a deep learning approach with satellite imagery]".

---

## Overview

This study examines the economic returns to education in the U.S. using ACS public-use microdata area (PUMA) data and uses distance to the nearest college as an instrumental variable. We use Multi-task Observational using Satellite Imagery and Kitchen Sinks (MOSAIKS) to control for geographical features that affect college accessibility. We additionally apply Double Selection (Lasso) to lower dimensionality. Results show there is a 19-20 percent wage increase per additional year of schooling at the baseline while controlling for selected 187, 195 image features output 17, 18 percent returns, respectively, suggesting higher returns to education for the marginal population and potential heterogeneity in spatial factors in local economies.
